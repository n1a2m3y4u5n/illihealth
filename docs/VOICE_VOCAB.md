# 음성 명령·안내 어휘 사전

이 사전은 STT(음성 인식) 결과를 액션으로 매핑하고, TTS(음성 출력)로 사용자에게 안내할 문구를 정의한다. 매칭은 정확 일치가 아닌 **키워드 포함 + 동의어 그룹** 방식으로 처리한다.

`lib/voice-intent.ts`는 이 파일의 명령 사전을 import하여 STT 결과를 인텐트로 분류한다.

---

## 전역 명령 (어느 화면에서나)

| 사용자 발화 | 동의어 | 액션 |
|---|---|---|
| 홈으로 | 처음, 메인 | router.push('/(main)/home') |
| 도와줘 | 도움, 살려줘, 응급 | SOS 응급 모드 활성화 |
| 취소 | 아니, 그만 | 현재 모달·다이얼로그 닫기 |
| 다시 | 한 번 더, 재시도 | 이전 동작 재실행 |
| 뒤로 | 이전 | router.back() |

## 매칭 규칙 구현 가이드

`lib/voice-intent.ts`는 다음 우선순위로 매칭한다:

1. **정확 키워드 일치** — 사전의 발화 문자열이 STT 결과에 포함되는지
2. **동의어 매칭** — 같은 행 안의 동의어 그룹도 동일 액션
3. **부분 매칭** — 핵심 키워드(예: "약", "병원")만 포함된 경우 가장 가까운 액션 후보 제시
4. **신뢰도 낮음** — 위 셋 모두 실패 시 "다시 말해줄래요?" TTS

언어별로 다른 사전을 두되, 공통 구조는 동일. `lib/voice-vocab/{lang}.ts` 형태로 분리.
